# PaperGuard User Journey

1. QC Staff login ด้วย demo account
2. ตรวจ Dashboard เพื่อเห็น lots ที่รอตรวจและ quality alerts
3. เปิด Production Lots
4. เลือก lot ที่ต้องการตรวจ
5. กรอก measured values ใน Quality Check
6. ระบบคำนวณผลแต่ละ item และ Overall Result แบบทันที
7. Submit เพื่อจบ demo workflow
